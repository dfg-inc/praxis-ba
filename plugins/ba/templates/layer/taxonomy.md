# Taxonomy — словарь тегов проекта

> Единый словарь тегов для всех артефактов: FS, US, BR.
> Используется для RAG-поиска и фильтрации.
> **Правило:** использовать только теги из этого списка. Новый тег — сначала добавить сюда.

---

## Функциональность

| Тег | Когда использовать |
|-----|--------------------|
| `crud` | Создание, чтение, обновление, удаление сущностей |
| `validation` | Проверка данных, ограничения на ввод |
| `calculation` | Автоматический расчёт значений |
| `search` | Поиск и фильтрация |
| `reporting` | Отчёты, экспорт данных |
| `notification` | Уведомления пользователю |
| `auth` | Аутентификация и авторизация |
| `access` | Права доступа к операциям/записям сверх базовой матрицы RBAC (BR-категория «доступ») |
| `onboarding` | Регистрация, первый запуск, обучение |

---

## Технические характеристики

| Тег | Когда использовать |
|-----|--------------------|
| `offline` | Работа без интернета |
| `api` | Взаимодействие через API |
| `integration` | Интеграция с внешней системой |
| `mobile` | Специфика мобильного устройства |
| `map` | Картографический интерфейс |
| `geo` | Геоданные, координаты, геометрия |
| `file-upload` | Загрузка файлов пользователем |
| `real-time` | Обновление данных в реальном времени |

---

## Данные и compliance

| Тег | Когда использовать |
|-----|--------------------|
| `data-migration` | Перенос или преобразование существующих данных |
| `data-integrity` | Целостность данных: обязательность, зависимости, инварианты (BR-категория «целостность») |
| `audit-trail` | Журналирование действий пользователя |
| `regulated` | Требования регулятора или юридические ограничения |
| `personal-data` | Персональные данные пользователей (GDPR и т.д.) |

---

## Как добавить новый тег

1. Убедись что ни один существующий тег не подходит
2. Добавь в нужную категорию с описанием
3. Обнови `updated` в этом файле
