# BA Code Surface Scan — детерминированное перечисление поверхности области

Read-only разведка кода: находит и перечисляет операции, ничего не интерпретирует и не пишет в артефакты. Существует, чтобы не терять рабочие функции при обычном («выборочном») чтении кода — см. инцидент в `ba-onboard`, Шаг 7 (функция «добавить из истории» была в коде, но не попала в AS-IS).

**Как запускать.** В изолированном контексте — агентом `Explore`, чтобы разбор кода не забивал основной контекст и не смешивался с интерпретацией. Вызывающий скилл передаёт агенту содержимое этого файла как задачу, подставив вместо `$ARGUMENTS`:

- имя области/среза;
- код-якоря — конкретные файлы/папки backend и frontend этой области (из Шага 2 `ba-onboard`).

**Возвращает:** два буквальных списка, без интерпретации смысла — её делает вызывающий скилл в своём контексте.

---

## Задача

Дано ниже — область и её код-якоря:

$ARGUMENTS

Выполни:

1. **Backend-поверхность.** Открой указанные файлы/папки роутов и перечисли ВСЕ объявленные в них маршруты — конструкции вида `@router...`, `@GetMapping`/`@PostMapping`, `app.get(...)`/`app.post(...)`, декораторы FastAPI/Express/Spring/Django и т.п. (смотри на стек проекта, не только на один фреймворк). Формат строки: `МЕТОД /путь -> файл:строка`.
2. **Frontend-поверхность.** Открой указанные экраны/компоненты и перечисли ВСЕ пользовательские действия: обработчики `onClick`/`onSubmit`/`onChange`, вызовы API/fetch/axios, отправку форм. Формат строки: `действие (кратко) -> файл:строка`.
3. **Полнота важнее краткости.** Не сокращай список для читабельности — пропущенная строка означает пропущенную фичу в AS-IS. Если внутри якоря есть подпапки или под-роуты — зайди и туда.
4. **Явно сообщай о пробелах.** Якорь не найден / пустой / не удалось открыть → напиши это прямо в отчёте (`⚠️ якорь <путь> не найден`), не пропускай область молча.
5. **Не интерпретируй.** Не пиши, что операция «означает» с точки зрения бизнеса, не предлагай требований и критериев приёмки, не ставь `[NEEDS CLARIFICATION]` — это шаг вызывающего скилла, не твой.
6. **Ничего не записывай.** Ни в `canon/`, ни в слой вокруг него: скан только читает и возвращает текст.

## Формат ответа

```
### Backend
МЕТОД /путь -> файл:строка
...

### Frontend
действие -> файл:строка
...

### Не найдено / нечитаемо
⚠️ ... (если применимо)
```

Ничего, кроме этих трёх секций, не возвращай — вызывающий скилл вставит список как есть в свою работу (сопоставление с поведением, сверка с требованиями).
